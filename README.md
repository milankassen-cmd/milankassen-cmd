## Data Science Projects (Time Series Analysis/Forecasting) 👋
In this repository I have added 3 data science projects to showcase what I have learnt. These projects relate to time series analysis,
financial engineering and machine learning. I have not showcased every technical skill within the data science field but these are some
skills that I have within the field.
<br>Python, SQL, Numpy, Pandas, Matplotlib, Plotly
PmdArima, Scikit-Learn, Scipy, StatsModels
Machine Learning, Time Series Analysis, Financial Analysis and Optimization </br>

<br> **Note:** All projects use the yfinance library to obtain the data, no data files are include because the library imports
the data directly when the notebook is run. Plotly is also the library used for visualizations and therefore cannot be rendered 
in Github, as the files are too large - notebooks will need to be run.

<br><ins> Project 1: Algorithmic Trading Strategies </ins></br>
This project explores a few different traditional algorithmic trading strategies, using the Dow Jones stock ticker. All of them are a simple Trend Following approach and we explore the use of Moving Averages. This is a basic time series analysis technique and is an important foundational skill
to have within this niche. Each strategy has its strengths and will be up to the hypothetical trader to decide which one to use,
taking into account the risk and potential returns.

<br><ins> Project 2: Portfolio Optimization (Finance) </ins></br>
The second project takes 10 assets or stock tickers and uses optimization methods(linear programming) and Modern Portfolio Theory to 
allocate assets based on the weights obtained. The weights are obtained by obtaining the risk and returns of each asset and assigning a percentage to the portfolio. Assets were chosen based on which companies are well known and would potentially yield large results and some assets were
chosen due to their brand name and not because they are expected to yield high returns - this shows a diverse portfolio.

<br><ins> Project 3: Currency Price Prediction (Time Series Forecasting) </ins></br>
This project aims to explore time series forecasting techniques and accurately they were able to capture the time series of the currency
exchange rate between the Rand and US Dollar (ZAR/USD). We use ARIMA, Dynamic Regression Dynamic Harmonic Regression and Linear Regression
to see which forecasting and analysis technique was best and most accurate given the volatile nature of currency prices which change on a
daily basis and are impacted by socio-economic and geo-political events.
